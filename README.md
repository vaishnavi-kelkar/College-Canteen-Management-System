# College Canteen Management System

A Java Swing-based desktop application for managing college canteen orders, billing, transactions, and inventory.

## Overview

This project provides a simple GUI-based canteen management system. Users can log in, select food items and quantities, calculate the order total, and place an order.

The system also calculates 5% tax, stores transaction information, and updates inventory stock using MySQL.

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- NetBeans

## Features

- User login authentication
- Food item selection
- Quantity selection
- Automatic running total
- 5% tax calculation
- Order summary
- Transaction storage
- Inventory stock update
- MySQL database connectivity
